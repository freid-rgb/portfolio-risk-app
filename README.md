# Portfolio Risk & Traits Tracker

Streamlit app: VaR (historical simulation), beta vs S&P 500, volatility,
Sharpe, drawdown, correlation, cost-basis weights, lot-level P&L, XIRR.

## Setup
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
